# Mijn PWA App

Progressive Web App (PWA) — works offline and can be installed on phone, tablet or computer.

## Files

| File | Purpose |
|---|---|
| `index.html` | The app itself |
| `manifest.json` | App manifest (name, icons, colors) |
| `service-worker.js` | Offline caching |
| `privacy.html` | Privacy policy |
| `user-guide.html` | User guide |
| `icon-192.png` | App icon 192×192 |
| `icon-512.png` | App icon 512×512 |
| `icon-maskable-512.png` | Maskable icon 512×512 |
| `icon.svg` | Optional vector icon |

## Install as app

- **Android (Chrome/Edge):** menu → "Install app"
- **iPhone/iPad (Safari):** Share icon → "Add to Home Screen"
- **Desktop (Chrome/Edge):** install icon in the address bar

## Offline use

After the first load, the app works without an internet connection.
